# خبریاب هوشمند — پلاگین وردپرس

پلاگینی برای وردپرس که:

1. **بر اساس فیدهای RSS تعریف‌شده** (هر فید = یک دسته‌بندی سایت) آخرین اخبار را می‌گیرد
2. از صفحه اصلی هر خبر، **تیتر + تصویر + متن کامل** را استخراج می‌کند
3. با **هوش مصنوعی** (API سازگار با OpenAI در `https://ai.ismc.ir/api`) و با **پرامپت تحریریه‌ای مخفی** (ضد تزریق دستورات از متن منبع):
   - **تیتر** خبری بازنویسی می‌شود
   - **لید** (یک یا دو جمله خبری) تولید می‌شود
   - متن کامل با تغییرات ساختاری بازنویسی و از ارجاعات منبع («به گزارش خبرگزاری ابنا» و ...) و پیشنهادی‌ها («همچنین بخوانید») پاک‌سازی می‌شود
   - ۵ تا ۸ **کلیدواژه** فارسی تولید می‌شود
4. نتیجه را به‌صورت **پیش‌نویس** (یا هر وضعیتی که تنظیم کنید) در دسته‌بندی انتخابی درج می‌کند — لید به‌عنوان پاراگراف اول (پررنگ)
5. **معماری صف‌دار**: چک فیدها و پردازش از هم جداست تا هاست‌های اشتراکی با timeout مواجه نشوند؛ خطاهای موقت با فاصلهٔ افزایشی دوباره امتحان می‌شوند

---

## نصب

1. پوشه `khabar-hiviz` را به `wp-content/plugins/` کپی کنید (یا فایل zip آن را از **افزونه‌ها ← افزودن** آپلود کنید).
2. افزونه را فعال کنید.
3. در منوی مدیریت، «**خبریاب هوشمند**» را باز کنید.

### ساخت خودکار دسته‌ها

هنگام **فعال‌سازی افزونه**، برای هر فید فعال، دسته‌ای به‌نام فید (بدون پسوند منبع) به‌صورت خودکار ساخته (یا دسته موجود با همان نام پیدا) می‌شود و به‌عنوان «دسته مقصد» همان فید ثبت می‌گردد:

| نام فید | دسته ساخته‌شده |
|---|---|
| اخبار سیاسی (خبرآنلاین) | اخبار سیاسی |
| اخبار اقتصادی (خبرآنلاین) | اخبار اقتصادی |
| ... | ... |
| فوتبال (خبرورزشی) | فوتبال |

اگر سایتتان قبلاً دسته‌ای با همین نام داشته باشد، **دسته جدید ساخته نمی‌شود** و همان استفاده می‌گردد. هر زمان که فید جدیدی اضافه کردید، در بخش ۲ دکمه «**ساخت خودکار دسته‌های کم‌تعداد**» را بزنید؛ فقط فیدهایی که دسته ندارند دست می‌خورند و دسته‌های انتخابی شما به‌هم نمی‌ریزد.

تنظیمات پیش‌فرض از همان‌اول پر شده‌اند:
- API: `https://ai.ismc.ir/api/v1` + کلید شما + مدل `qwen38-sglang` (همان qwen38 با موتور سریع؛ قابل تغییر به qwen38 یا qwen38-nothinking)
- **۲۱۲ فید پیش‌فرض از ۴۱ سایت** در ۸ موضوع (سیاسی، اقتصادی، فرهنگی و هنری، اجتماعی، بین‌الملل، ورزشی، دانش و فناوری، فوتبال):
  - ۱۸۷ فید از ۱۶ سایت که **فید به فید و با تطبیق تیترها تأیید شده‌اند**: خبرآنلاین، ایرنا، ایسنا، مهر، خبرورزشی، تبیان، آنا، میزان، ایران اینترنشنال، دنیای اقتصاد، شرق، دانشجوی (snn.ir)، اقتصاد آنلاین، ورزش سه، سایما (سپیدار)، پارس نیوز.
  - ۲۵ فید «منابع تکمیلی» از ۲۵ سایت شناخته‌شده دیگر (تسنیم، تندار، ایبنا، برگ، سازندگی، جمهوری، خبر ۸، خبر ۳، زمین، انتخاب، بیان ۲۴، دنیای نفت، کیهان، اطلاعات، فرهنگیان، پرس ۲۴۷، ملت ۱۱۳۰، همشهری، تبناک، اسپرتنا، بورس ۲۴، فوتبال آنلاین، پارسی‌دروید، ایران‌وایر، وطن اقتصاد) که از شبکه‌ی توسعه قابل‌بررسی نبودند؛ آدرس‌های استاندارد فید هر سایت داده شده است. اگر فیدی کار نکند، از پنل غیرفعالش کنید.
- چک فیدها هر ۵ دقیقه (با ۳ گروه چرخشی؛ یعنی در عمل هر فید هر ~۱۵ دقیقه یک‌بار اسکن می‌شود) + پردازش صف هر ۱ دقیقه (سقف ۳ خبر در هر تیک)، درج به‌صورت پیش‌نویس، تصویر مستقیم از CDN مبدأ، کلیدواژه‌ها به‌صورت برچسب

> ✅ با فعال‌سازی افزونه، دسته‌های مقصد (اخبار سیاسی، اقتصادی، ...) خودکار ساخته و به فیدها متصل می‌شوند. اگر دسته‌های سایت شما نام دیگری دارند، بعد از فعال‌سازی در صفحه تنظیمات دسته مقصد هر فید را عوض کنید.

## تنظیمات (همه قابل تغییر است)

| بخش | گزینه | پیش‌فرض |
|---|---|---|
| ۱. هوش مصنوعی | آدرس API، کلید (**رمزنگاری‌شده در دیتابیس**؛ در فرم فقط ماسک `••••••••` نمایش داده می‌شود — فیلد خالی = حفظ کلید فعلی، مقدار جدید = جایگزینی)، مدل (فهرست **فقط مدل‌های گفتگویی** از API خوانده می‌شود: `qwen38`، `qwen38-sglang`، `qwen38-nothinking`؛ مدل‌های embedding/ASR صِرف هستند)، دکمه تست اتصال | `qwen38-sglang` |
| ۲. فیدها | جدول: نام فید / آدرس / **دسته مقصد** / فعال / حداکثر تعداد خبر در هر چک / **تست RSS** (تست زنده هر فید) + دکمه **ساخت خودکار دسته‌های کم‌تعداد** | ۲۱۲ فید پیش‌فرض از ۴۱ سایت (۸ موضوع) |
| ۳. درج پیش‌نویس | نوع پست (post یا هر CPT عمومی)، وضعیت (draft/publish/pending)، بازه چک فیدها (۵ دقیقه تا روزی یا فقط دستی)، سقف خبر در هر تیک پردازش صف (هر ۱ دقیقه)، **تعداد گروه‌های اسکن** (هر چک فقط یک گروه از فیدها به‌صورت چرخشی اسکن می‌شود؛ برای سایت‌های پرفید) | post + draft + چک هر ۵ دقیقه + ۳ خبر در هر تیک + ۳ گروه |
| ۴. متن/تصویر/کلیدواژه | تصویر: مستقیم از CDN یا دانلود به رسانه؛ کلیدواژه: برچسب / Yoast / RankMath / فیلد اختصاصی؛ ذکر منبع: بدون / یک خط «منبع: ...»؛ رد کردن دسته‌های فیدی مثل «ویدیو»؛ حداکثر کاراکتر متن ارسالی به AI | برچسب + بدون منبع + رد «ویدیو» |
| ۵. اجرا، صف و لاگ | دکمه **اجرای فوری** + **توقف/ادامه پردازش** + **شروع از این لحظه** (نادیده‌گرفتن خبرهای قدیمی) + نمایش تعداد صف + **لاگ** کامل (آخرین ۲۰۰ رویداد) | — |

### امنیت کلید API

کلید API **هرگز به‌صورت متن ساده در دیتابیس ذخیره نمی‌شود**:

- قبل از ثبت در `wp_options` با **AES-256-GCM** رمزنگاری می‌شود؛ کلید رمزنگاری ۲۵۶ بیتی از `wp_salt()` سایت (حالت `auth`) + آدرس سایت با HMAC-SHA256 مشتق می‌شود، پس در هر نصب منحصر‌به‌فرد است.
- در صفحه تنظیمات فقط ماسک `••••••••` نمایش داده می‌شود؛ کلید واقعی به HTML و براکز ارسال نمی‌گردد.
- اگر فیلد کلید را **خالی** بگذارید، کلید فعلی حفظ می‌شود؛ برای تغییر، کلید جدید را وارد کنید.
- مقادیر قدیمی (متن ساده) در اولین ذخیره‌ی بعدی **خودکار مهاجرت** و رمزنگاری می‌شوند.
- اگر سرور openssl نداشته باشد (بسیار نادر)، کلید به‌جای متن ساده با base64 ذخیره می‌شود.

## نحوه کار (معماری صف‌دار)

```
رویداد ۱: اسکن فیدها (با بازه انتخابی، پیش‌فرض هر ۵ دقیقه)
  └─ برای هر فید فعال:
       └─ دریافت XML فید
            └─ برای جدیدترین آیتم‌های پردازش‌نشده (حداکثر N از هر فید):
                  ├─ رد اگر دسته آیتم شامل «ویدیو» (یا skip_cats) باشد
                  ├─ رد اگر قدیمی‌تر از نقطهٔ شروع («شروع از این لحظه») باشد
                  ├─ لینک کانونیکال: https://site.com/news/123456/
                  ├─ بررسی تکراری‌بودن (بر اساس آدرس کانونیکال)
                  └─ افزودن به صف انتظار (به ترتیب تازگی زمان انتشار)

رویداد ۲: پردازش صف (هر ۱ دقیقه، سقف «حداکثر خبر در هر تیک»)
  └─ برای هر خبر صف:
       ├─ دریافت صفحه خبر → استخراج متن از [itemprop=articleBody] + og:image
       ├─ فراخوانی AI → { TITLE, LEAD, BODY, KEYWORDS }
       ├─ ساخت پست draft + لید پررنگ + بدنه + دسته + برچسب‌ها + تصویر شاخص + متا (آدرس منبع)
       └─ در صورت خطا: برگشت به صف با فاصلهٔ افزایشی (۱، ۲، ۴، ... دقیقه)؛ بعد از ۵ تلاش حذف
```

- اگر هوش مصنوعی بعد از **۳ تلاش** در دسترس نباشد، خبر با **تیتر اصلی و متن اصلی** (پاک‌سازی‌شده با منظم‌های محلی از «به گزارش ...» و ...) درج می‌شود و در لاگ ثبت می‌گردد.
- اگر متن کامل خبر به‌دست نیاید، از توضیح (`description`/`content`) فید استفاده می‌شود؛ اگر آن هم زیر ۳۰۰ کاراکتر باشد، خبر با فاصله به صف برمی‌گردد.
- خروجی هوش مصنوعی با قالب فیلدی سخت‌گیرانه خوانده می‌شود (TITLE/LEAD/BODY/KEYWORDS) و در صورت شکست، JSON هم امتحان می‌شود؛ اگر نه، خبر دوباره امتحان می‌شود.
- **توقف پردازش**: فیدها همچنان چک و صف پر می‌شود، ولی خبری پردازش نمی‌شود (مناسب برای زمانی که سایت در حال به‌روزرسانی است).
- **شروع از این لحظه**: فقط خبرهای منتشرشده *بعد از* آن لحظه پردازش می‌شوند و صف کنونی خالی می‌شود.
- اجرای هم‌زمان (cron + دکمه دستی) با قفل جداگانه برای هر دو رویداد جلوگیری می‌شود.

## نکات مهم

- **Cron وردپرس** فقط با ترافیک بازدید اجرا می‌شود. اگر سایت کم‌ترافیک است، یا از cron سیستمی استفاده کنید:
  ```
  * * * * * wget -q -O - https://mysite.com/wp-cron.php >/dev/null 2>&1
  ```
  یا افزونه‌هایی مثل «Always Online» را نصب کنید.
- در حالت تصویر «مستقیم از CDN»، تصویر به‌صورت attachment با آدرس خارجی ثبت می‌شود و `wp_get_attachment_url()` آدرس CDN را برمی‌گرداند؛ اگر CDN مبدأ مسدود یا حذف شود تصویر نمایش داده نمی‌شود. در این حالت گزینه «دانلود به رسانه» را فعال کنید.
- متاهای هر پست برای ردیابی: `_khv_source_url` (آدرس خبر اصلی به شکل کانونیکال)، `_khv_feed_name`، `_khv_original_title`، `_khv_source_name`.

```
│   ├── class-khv-article.php         # دریافت صفحه خبر + استخراج متن/تصویر
│   ├── class-khv-cron.php            # زمان‌بندی و قفل اجرا
│   ├── class-khv-feeds.php           # دریافت و تفسیر XML فید
│   ├── class-khv-log.php             # لاگ رویدادها
│   ├── class-khv-processor.php       # صف انتظار، اسکن فیدها، پردازش صف، retry/backoff
│   ├── class-khv-settings.php        # تنظیمات و اعتبارسنجی (+ رمزنگاری کلید API)
│   └── default-feeds.php             # ۲۱۲ فید پیش‌فرض از ۴۱ سایت (فیلتر: khv_default_feeds)

    ├── class-khv-admin.php           # صفحه مدیریت، ذخیره، ajax (تست/اجرا)
    ├── views/settings.php            # فرم تنظیمات (RTL)
    ├── admin.css
    └── admin.js                      # افزودن/حذف فید، تست AI، اجرای فوری
```
